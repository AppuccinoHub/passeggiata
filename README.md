# Passeggiata

Dodici passeggiate serali, in italiano. Ogni sera è la fotografia della via: una sera lunga a Lecce, poi tre notti a Torino. Entri nella foto e rispondi a chi hai davanti. Il mestiere è la distanza. Chi riceve il ciao, chi il buonasera, e quando una frase da libro suona fredda.

Ogni passeggiata si può leggere. La successiva conta solo quando la precedente è finita. Il percorso resta nel browser.

## Run it

```bash
npm install
npm run build
npm start
```

Open [http://localhost:3847](http://localhost:3847). Reload if a previous tab is still spinning: that tab was waiting on a dev socket that never arrives.

Femminile e maschile, per le frasi che dici, è un interruttore in alto. Cambia parole come *aspettata* / *aspettato*. La sera non cambia.
